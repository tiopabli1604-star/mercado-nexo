# Instalación local

Node.js 24 o superior. npm ci; npm run build; npm start. Visita http://127.0.0.1:3001. En Windows: Abrir Mercado Nexo.cmd. Sin cuentas ni claves de proveedor.

El proceso sirve la interfaz y evalúa alertas. Mantenerlo activo. No se ha desplegado un servicio público, DNS, certificado TLS o proceso de inicio automático. Puerto 3000 queda reservado para Trazo de Mesa. La configuración permite PORT y DATA_DIR mediante variables de entorno del proceso.

Parar el proceso antes de copiar .data como respaldo completo. No publicar esa carpeta, ni habilitar red externa sin implementar autenticación. Se entrega código fuente y lockfile; la compilación dist se genera localmente y no se versiona.
