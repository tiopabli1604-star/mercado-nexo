# Comparación honesta de alcance

Ver parity-score.md para el cálculo automático sobre 49 filas elegibles de este alcance reducido. No es un porcentaje de todo TradingView. Cinco exclusiones no puntúan. El reconocimiento es documental y no se ejecutó diff visual por ausencia de capturas equivalentes del original.

Los cinco módulos elegidos están operativos para ocho pares USD de Coinbase.
